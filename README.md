Como Utilizar o Filtro do PrimeHub

Para que o filtro funcione corretamente, siga atentamente as instruções abaixo:

Pasta do Launcher:
Para utilizar o filtro, ele deve estar obrigatoriamente localizado na mesma pasta de instalação do launcher do Prime.

Atualização dos Arquivos:
Quando você colocar o Hub na mesma pasta, abra o aplicativo e clique no botão "Atualizar". Isso fará o download automático de todos os arquivos necessários para o correto funcionamento do filtro.

Ativação In-Game (Ctrl + R):
Sempre que você for utilizar ou alterar as configurações do filtro, lembre-se de pressionar as teclas Ctrl + R dentro do jogo para recarregar e aplicar o filtro.
